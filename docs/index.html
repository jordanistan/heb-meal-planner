Run it in one command

The whole stack — web, API, and Postgres — via Docker Compose.

git clone https://github.com/jordanistan/heb-meal-planner.git
cd heb-meal-planner
docker compose up -d --build
  1. Open localhost:3000 — the app.
  2. Pick a diet/protein, cuisines, and your anchor meals.
  3. Set a budget (optional) and hit Generate plan.
  4. Tap Find → on any item to open it on heb.com.

Prefer no Docker? See the local dev steps. Want AI-generated cooking steps? Add an ANTHROPIC_API_KEY.
